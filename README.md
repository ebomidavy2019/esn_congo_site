# Site vitrine ESN Congo Consulting IT

## Contenu
- `index.html` : page d'accueil et toutes les sections du site.
- `css/style.css` : styles personnalisés (palette bleue, verte et blanche).
- `js/script.js` : année automatique, navigation mobile et formulaire de contact par e-mail.
- `assets/` : les deux brochures fournies.

## Lancer le site
1. Décompresser le dossier `esn_congo_site`.
2. Ouvrir `index.html` dans un navigateur.
3. Une connexion Internet est nécessaire pour charger Bootstrap 5, Bootstrap Icons et Google Fonts depuis leurs CDN.

## Personnalisation
Les coordonnées visibles dans les brochures ont été reprises dans la page Contact.
Le formulaire prépare un e-mail via l'application de messagerie du visiteur. Il ne stocke pas les messages sur un serveur.
Pour un formulaire réellement opérationnel sans application e-mail, il faudra ajouter un backend (PHP, Laravel, ASP.NET, etc.).
